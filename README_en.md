# Data
## Tarkov Sensitive Data
By default, this project hashes any Tarkov sensitive data it reads to protect privacy.
This behavior is controlled by the class attribute `tarkov_tool.config.Config.enable_sensitive_data_hashing_for_tarkov`.

Tarkov sensitive data includes but is not limited to:
 - AccountID
 - ProfileID

>[!NOTE]
>This behavior is designed to hash the data upon reading and parsing before output.

# Terminology
|Term|Description|Notes|
|-|-|-|
|Game Session|The complete lifecycle of a game process. From game start to end (process termination also counts as end) constitutes one Session.||
|Raid|Refers to a raid within the game. Typically the process of a player entering a map, completing tasks or combat, and extracting.|Even if the raid_id differs after transitioning to another map, it is still considered the same raid (based on the game's determination of the same raid).|
|Raid Session|A component of a Raid, describing "different segments of the same raid".|Due to situations like disconnection and reconnection, or map transitions, the same Raid may be split into multiple Sessions.|
|Raid Group|Refers to the members of the squad who entered the raid together as teammates.|Due to server issues, the actual members may not match those recorded in the logs.|

> Based on observations, the above terms have the following relationships:
>
> A Raid consists of one or more Raid Sessions.
>
> Generally, a Raid only has one corresponding Raid Group; if there is a map transition, there may be different Raid Groups.
>
> The same Raid may span different Game Sessions, for example, if the player voluntarily restarts the game or the game crashes unexpectedly.

# Data Differences
The developer used a PVE Profile created before game version 1.0 to play the game and obtained logs for the development of this project.
Therefore, there may be differences from logs generated by PVE Profiles created after version 1.0.

For details on the game versions corresponding to the referenced log files, please check [notes\used_tarkov_log_versions.txt](notes\used_tarkov_log_versions.txt).
