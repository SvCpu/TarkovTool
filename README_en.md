# Data
## Tarkov Sensitive Data
This project will hash any Tarkov sensitive data it reads by default to protect privacy
This behavior is controlled by the class attribute `tarkov_tool.config.Config.enable_sensitive_data_hashing_for_tarkov`

Tarkov sensitive data includes but is not limited to:
 - AccountID
 - ProfileID

>[!NOTE]
>This behavior is designed to hash data upon reading and parsing before output

# Terminology
|Term|Description|Notes|
|-|-|-|
|Game Session|Refers to the complete lifecycle of a game process. From the start to the end of the game process counts as one Session||
|Raid|Refers to a raid within the game. Usually the process of a player entering a map, completing tasks or combat, and extracting|After transferring to another map, even if the raid_id is different, it is still considered the same raid (based on how quests determine the same raid)|
|Raid Session|Refers to the components of a Raid, describing "different segments of the same raid"|Due to possible disconnections and reconnections, map transfers, etc., the same Raid may be split into multiple Sessions.|
|Raid Group|Refers to members of a squad who enter a raid together as teammates|Actual members may differ from those recorded in the logs due to server issues|

> Based on observed records, the above terms have the following relationships
>
> A Raid consists of one or more Raid Sessions
>
> Generally, a Raid will only have one corresponding Raid Group; if there is a map transfer, there may be different Raid Groups
>
> The same Raid may span different Game Sessions, for example due to the player actively restarting the game or the game crashing
