# About
This project was originally created to learn Python and explore Tarkov's log information (who would have thought logs could be several GB).

The project is still in development, without any usage documentation.

Predecessor of this project: [TarkovParser](https://github.com/SvCpu/TarkovParserArchive)

# Data
## Tarkov Sensitive Data
This project by default hashes any Tarkov sensitive data it reads to protect privacy.
This behavior is controlled by the class attribute `tarkov_tool.config.Config.enable_sensitive_data_hashing_for_tarkov`.

Tarkov sensitive data includes but is not limited to:
 - AccountID
 - ProFileID

>[!NOTE]
>This is designed so that when data is read and parsed, it is hashed before being output.

# Terminology
|Term|Description|Notes|
|-|-|-|
|Game Session|Refers to a complete lifecycle of a game process. From the start to the end of the game process counts as one Session.||
|Raid|Refers to a single raid in the game. Typically the process of a player entering a map, completing tasks or combat, and extracting.|Even after transferring to another map, even if the raid_id is different, it is still considered the same raid (based on the game's determination of a single raid).|
|Raid Session|Refers to a component of a Raid, describing "different segments of the same raid".|Due to situations such as disconnection and reconnection, map transitions, etc., the same Raid may be split into multiple Sessions.|
|Raid Group|Refers to the members of a squad who entered a raid together as teammates.|Due to server issues, the actual members may not match those recorded in the log.|

> Based on existing observations, the above terms have the following relationships:
> 
> A Raid consists of one or more Raid Sessions.
> 
> Generally, a Raid only has one corresponding Raid Group; if there is a map transition, there may be different Raid Groups.
> 
> The same Raid may span different Game Sessions, for example due to the player actively restarting the game or an unexpected game exit.

# Data Differences
The developer used a PVE Profile created before game version 1.0 to play and obtained logs for developing this project.
Therefore, there may be differences from logs generated by PVE Profiles created after version 1.0.

For details on the game versions corresponding to the referenced log files, please check [notes\used_tarkov_log_versions.txt](notes\used_tarkov_log_versions.txt)
