# TarkovTracker_tarkovdata

社群維護的逃離塔科夫遊戲數據集，以結構化 JSON 格式提供。

由 Tarkov Tracker、Tarkov Guru、tarkov.dev 等工具開發者共同維護。

包含以下 JSON 資料：

- `quests.json` — 任務資料
- `hideout.json` — 藏身處數據（工作站與升級模組）
- `items.en.json` — 物品名稱（英文）
- `traders.json` — 商人資訊
- `maps.json` — 地圖元數據
- `ammunition.json` — 彈藥數據
- `item_presets.json` — 物品預設配置（武器改裝）
- `levels.json` — 等級經驗對照表
- `objective_gps.json` — 任務目標 GPS 座標
- `objective_maps.json` — 任務目標對應地圖
- `task_alternatives.json` — 任務替代路線
